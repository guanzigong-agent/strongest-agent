# 最强经纪人

一款手机优先的 NBA 球员交易网页小游戏：访问球队、查看报价、买入球员、换队卖出，经营 30 天。

## 本地运行

需要 Node.js 20 或更新版本，无需安装产品依赖。

```powershell
npm start
```

打开 http://127.0.0.1:4173/ 。请使用 HTTP 服务，直接双击 HTML 会受到浏览器模块与数据读取限制。

## 玩法

- 初始资金 1500 万美元；仓库最多 5 人。
- 30 支真实球队、开局名单 522 名球员均挂牌可买；买入后进入仓库，卖出后加入目标球队。
- 每次移动消耗一天，同队不能重复移动；买卖不耗天数。
- 基准为快照赛季当季年薪。球队位置需求、真实比赛表现及已收录新闻影响报价，范围为年薪的 70%—130%。同一天报价固定。
- 其他球队只显示访问时的历史报价，玩家根据资讯选择下一站。
- 第 30 天不能再移动，仍可交易。结算包括现金和统一持仓参考价值，不含最后所在地的球队偏好；可提前结束。
- 自动保存到当前浏览器本地存储。浏览器拒绝保存时页面持续提醒，当前会话仍可继续；不同设备不会同步。

## 数据范围

当前是 **2025–26 赛季历史回放**，日期为 **2025-10-21 至 2025-11-19**，不是 2026-10-03 的实时阵容或资讯。

当前快照含 30 队、522 名球员、4,799 条比赛表现、222 场比赛结果与 5 条精选新闻；其中 2 条新闻编码影响价格。开局前最近最多 5 场已收录季前赛构成表现基准，基准缺失时不计算相对表现影响。

阵容采用有固定提交版本的社区开季名单，以历史技术统计核对球员身份；**尚未完成逐队官方全量名单核验**。薪资采用 SalarySwish 当季 Base Salary；KJ Simpson 的年度基准按已确认双向合同和当季全季标准计算，明确区别于实际到账与后来签订合同。详见 [数据来源与限制](docs/data-sources.md)。

## 验证

```powershell
npm test
npm run validate
python tests/test_salary_parser.py
```

Python 只用于公开数据整理，不是游戏运行依赖。浏览器回归需本机已可用的 Playwright 与测试浏览器；脚本通过 `PLAYWRIGHT_MODULE`、`TEST_BROWSER` 环境变量选择环境，均不写入仓库。运行 `node scripts/browser-smoke.mjs`。不使用桌面控制。

## GitHub Pages

发布根目录只需要 `index.html`、`styles.css`、`src/`、`data/` 和 `docs/data-sources.md`。所有资源采用相对路径，支持 `https://<账号>.github.io/<仓库>/`。

推荐启用仓库 Settings → Pages → Source: GitHub Actions，再使用本仓库的 Pages workflow。workflow 只打包运行资源；测试、采集缓存、任务上下文和凭据不进入部署包。

当前尚未上传 GitHub、尚未启用 Pages；发布需要明确的账号与仓库以及可用登录权限。
