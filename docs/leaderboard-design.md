- 排名建议口径为现金加持仓统一模拟参考价值，排除目的地球队需求溢价；按总资产降序。同一难度本金相同，总资产与净收益的排序一致。

- 当前局结束后退出进行中榜单；本轮演示保留查看入口并解释退出原因。正式活动玩家筛选、离线保留时间与过期规则尚待确定。

## 真实同步接入边界

GitHub Pages提供静态HTML、CSS和JavaScript托管，不能单独充当共享成绩数据库和实时同步服务。官方说明：<https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages>。

实际发布可以继续使用既定GitHub仓库与Pages；排行榜另接云端成绩服务。服务选型、身份方案与配置在界面确认后的工程阶段确定。本轮未创建外部项目、接入账号、上传昵称或成绩，也未开始正式后端实现。

正式服务需要根据局ID、玩家ID、难度、数据快照及规则版本校验游戏事件并重算成绩，避免直接信任浏览器提交的总资产。成绩验证成功后推送排名变化；断线恢复时获取完整榜单。不同规则或数据版本的成绩不能静默混排。

## 验收关注

- 三个难度的玩家数据隔离；当前玩家只出现在当前难度。
- 开局、买入、卖出、移动后的资产与天数正确；排名更新不改变游戏资金或交易状态。
- 排名包含本人位置，长昵称与金额在手机和桌面可读。
- 模拟玩家、断线和未联网状态明确标注，前端演示不声称真实多人实时功能已完成。
- 正式实时延迟、服务端重算、跨设备身份与异常成绩处理需在云端接入后另行验证。
