# 最强nba人贩子：数据来源与覆盖说明

版本：2025-26-opening-v1。采集日期：2026-10-03。游戏内日期采用比赛举办地的 NBA 日历日期，按整日收录；不模拟盘中资讯发布时间。

## 阵容

[NBA 官方开季名单索引](https://www.nba.com/news/nba-rosters-set-for-2025-26-regular-season)提供球队链接，但其中部分名单页会更新，不能将今天读取的名单当作历史证据。

因此本版使用 [固定于 2025-10-22 的社区开季数据](https://github.com/alexnoob/BasketBall-GM-Rosters/blob/3ee24e048ebcc1ba851b13f32309929bf82ea521/2025-26.NBA.Roster.json)中的姓名、球队归属和位置，共 522 名球员。只使用事实字段，不使用其平均合同金额、游戏评分、照片或能力模型。球队基本信息及球员身份通过 ESPN 历史比赛技术统计交叉核对；暂未完成每队官方完整开季名单复核，不能把名单标记为官方全量核验通过。

## 当季合同基准

采用 [SalarySwish](https://www.salaryswish.com/)球员合同历史中的 **2025-26 Base Salary**，不采用 Cap Hit、剩余合同总额、平均合同额或实际到账金额。仅选择 2025-10-21 前签署且覆盖该赛季的最近合同；排除后续新合同与 DEAD CAP 表。双向合同按全季基准报价，不按出场次数计价。

例如 [东契奇](https://www.salaryswish.com/players/luka-doncic)当季基准为 45,999,660 美元；[Nick Smith Jr.](https://www.salaryswish.com/players/nick-smith-jr)开局使用当时双向合同 636,434 美元，排除后来转正金额和前东家裁员残留金额。

KJ Simpson 属单独计算项：[黄蜂官方签约公告](https://greensboro.gleague.nba.com/news/charlotte-hornets-sign-kj-simpson-to-two-way-contract)确认双向合同，采用 [2025-26 全季双向标准](https://www.salaryswish.com/minimum-salary-calculator/2026) 636,434 美元作为年度基准；`salaryStatus=calculated-two-way`。该数字是游戏按合同类型计算的赛季标准，不是其实际到账证明。

各球员对应 URL 保存于 snapshot.json 的 sources；主薪资来源多数为单一专业数据库，尚未完成全部合同交叉复核。所有当前名单均有正数基准与来源；有来源不等于最终官方核验。

## 比赛与新闻

比赛来自 ESPN 历史 scoreboard 和 summary 技术统计：2025-10-21 至 2025-11-19 共 222 场已结束比赛；保留名单内球员 4,799 条出场技术统计。前 10 个自然日的已收录季前赛，用每人最后最多 5 场 Game Score 均值建立基准，共 433 人有基准。缺基准不伪造能力值，不计算相对表现价格项。

Game Score 使用得分、投篮、罚球、前后场篮板、抢断、助攻、盖帽、犯规与失误构成固定统计指标；游戏不是对球员真实价值的专业估值。

5 条精选新闻来自 NBA 官方站，保留日期、简短事实和原文链接。只对有明确缺阵或复出证据的 2 条新闻编码影响；训练进度、纪律处罚等仅供玩家阅读。覆盖并不完整，不代表全联盟全部新闻或完整伤病报告。新闻编码与幅度属于游戏设计参数。

## 报价规则

- 比赛：截止当日最后最多 5 场 Game Score 均值与开局前基准比较。基准分母最低 5，偏差达到 ±10% 或 ±25% 时分别影响 ±3% 或 ±6%。
- 新闻：已编码伤病缺阵 -8%，明确复出 +5%；发生后按 7 天线性衰减，累计事实影响限制在 ±22%。
- 球队：按开局 G/F/C 人数与联盟平均差，每差 1 人影响 2%，限 ±8%；不会随游戏内转会重新定义球队需求。
- 当地报价：年薪乘以 1 + 事实影响 + 球队偏好，限制在 70%—130%，四舍五入到整数美元。
- 结算参考价值：年薪乘以 1 + 事实影响，不含球队偏好。

前往球队才更新该队可见历史快照；当天买卖不重抽价格。新闻与统计不会因玩家交易改写。页面没有其他球队实时价格或价格预测。

## 已知限制

本版用于可玩性验证；开季社区名单比逐日正式交易记录更简化，后续现实中的转队不会改变游戏开局归属。真实历史信息只推动报价，游戏交易独立改变虚拟归属。合同薪资是固定赛季基准，不模拟 NBA 真实转会规则或劳资协议审批。

正式上线前，仍需逐队复核官方阵容、交叉核查全部薪资、扩充新闻覆盖，并核查数据／素材公开使用要求及虎扑正式接入文档。
